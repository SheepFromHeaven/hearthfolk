# Hearthfolk

Hearthfolk is a NeoForge mod for Minecraft 26.3 that makes vanilla villagers work. There is no new mob, no banner to plant and no menu to open. You build the farm, the mine or the loom, and the villager who owns it gets on with the job.

Start here:

- [Getting Started](Getting-Started): install it, build your first working village
- [How Villages Work](How-Villages-Work): villages, beds, chests, money, food, children, defence
- [Professions](Professions): what every job does and what it needs from you
- [Settings](Settings): every switch and what it changes
- [Customizing with Data Packs](Customizing-with-Data-Packs): change prices, recipes, names and more with JSON
- [Commands and the Inspector](Commands-and-the-Inspector): find out why a villager is idle
- [Troubleshooting](Troubleshooting)

The mod was called MineNow before it was renamed. The mod id, packages, config file (`minenow-local.toml`) and data namespace are still `minenow`, so old worlds keep working.
